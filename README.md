## Description
This project is a simple football game developed using Python.
The player can perform different football actions, score goals,
and try to keep their points and lives.

The project uses Python classes, functions, conditional
statements, loops, and user input.

## How to Play
1. Run the Python program.
2. Follow the instructions displayed on the screen.
3. Enter your choice to perform a football action.
4. Try to score goals and increase your points.
5. Keep your lives and avoid losing all of them.
6. The game ends when all lives are lost.
